# Лабораторная работа №4: Исключения и работа с ресурсами в Java

## Описание

Данная работа посвящена углубленному изучению механизмов обработки исключений в Java. Основная цель — научиться изолировать потенциально опасный код, корректно обрабатывать стандартные ошибки (например, ошибки ввода-вывода или преобразования типов) и создавать собственные классы исключений для специфических ситуаций. Также реализована логика безопасной работы с ресурсами (файлами и потоками ввода) и запись ошибок в лог-файл.

## Ключевые концепции

*   **Иерархия Exception:** Обработка проверяемых (Checked) и непроверяемых (Unchecked) исключений.
*   **Блоки Try-Catch-Finally:** Использование `try` для выполнения кода, `catch` для перехвата ошибок и `finally` для гарантированного освобождения ресурсов.
*   **Собственные исключения:** Создание класса `CustomDivisionException`, наследуемого от `Exception`, для точного описания бизнес-ошибок (деление на ноль).
*   **Работа с ресурсами:** Использование ручного управления ресурсами в блоке `finally` и конструкции `try-with-resources` для автоматического закрытия потоков.
*   **Логирование:** Механизм сохранения информации об исключениях в текстовый файл `exceptions_log.txt` для последующего анализа.

## Содержание работы

### 1. Вычисление среднего арифметического (`ArrayAverage`)

Программа рассчитывает среднее значение элементов массива с защитой от некорректного ввода пользователя.

*   **Обработка ошибок:**
    *   `NumberFormatException`: Перехватывается, если пользователь вводит текст вместо числа при задании размера или элементов массива.
    *   `ArrayIndexOutOfBoundsException`: Перехватывается, если количество введенных элементов меньше заданного размера массива.
*   **Управление ресурсами:** Объект `Scanner` закрывается в блоке `finally`, чтобы избежать утечки ресурсов.

### 2. Безопасное копирование файлов (`FileCopy`)

Комплексная задача по передаче данных между файлами с использованием байтовых потоков.

*   **Реализация:** Чтение из `source.txt` и запись в `destination.txt` происходит побайтно с помощью `FileReader` и `FileWriter`.
*   **Безопасность:** Используется классическая схема обработки исключений с ручным закрытием потоков.
*   **Блок finally:** Содержит вложенные конструкции `try-catch` для независимого закрытия `reader` и `writer`. Это гарантирует, что при возникновении ошибки ресурсы будут корректно освобождены, даже если поток чтения или записи открылся с ошибкой.

### 3. Пользовательские исключения и логирование (Вариант 1)

Реализован механизм кастомной обработки математической операции и ведения журнала ошибок.

*   **Класс `CustomDivisionException`:**
    *   Собственный класс исключения, наследуемый от `Exception`.
    *   Используется для генерации ошибки при попытке деления на ноль с информативным сообщением.

*   **Класс `DivisionProgram`:**
    *   **Метод `divide(double a, double b)`:** Проверяет делитель. Если `b == 0`, выбрасывает `CustomDivisionException`.
    *   **Метод `log(String text)`:** Записывает переданный текст в файл `exceptions_log.txt`. Использует конструкцию `try-with-resources` (try с параметром) для `FileWriter`, что обеспечивает автоматическое закрытие файла после записи.
    *   **Логика программы:** Считывает два числа, выполняет деление. При возникновении ошибок (как собственных, так и `NumberFormatException`) в консоль выводится сообщение, а детали ошибки записываются в лог-файл.
