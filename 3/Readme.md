# Лабораторная работа №3: Хэш-таблицы и обобщения в Java

## Описание

Данная работа посвящена изучению структуры данных «Хэш-таблица», механизмов разрешения коллизий и практическому применению дженериков (Generics) для создания универсальных контейнеров данных. Проект разделен на две части: реализацию собственной хэш-таблицы с использованием метода цепочек и решение прикладной задачи по учету автотранспорта с использованием встроенной коллекции `HashMap`.

## Основные концепции

*   **Хэш-таблица:** Структура данных, хранящая пары «ключ-значение», использующая хэш-функцию для вычисления индекса в массиве.
*   **Метод цепочек (Chaining):** Способ разрешения коллизий, при котором каждая ячейка массива содержит связный список (`LinkedList`) элементов с одинаковым хэш-кодом.
*   **Дженерики (<K, V>):** Использование параметризованных типов для создания класса `HashTable`, способного работать с любыми типами данных (String, Integer, пользовательские объекты).
*   **HashMap:** Использование стандартной реализации хэш-таблицы из пакета `java.util`.

## Реализация заданий

### 1. Универсальная хэш-таблица (`HashTable<K, V>`)

Реализован собственный класс, имитирующий поведение стандартных коллекций с использованием обобщений.

*   **Внутренняя структура:**
    *   Массив `LinkedList<Entry<K, V>>[]` для хранения данных и разрешения коллизий.
    *   Вложенный статический класс `Entry` для хранения пар ключ-значение.
*   **Основные методы:**
    *   `put(K key, V value)`: Вычисляет хэш ключа, добавляет пару в список. Если ключ уже существует, обновляет значение.
    *   `get(K key)`: Ищет значение по ключу в соответствующем списке.
    *   `remove(K key)`: Удаляет пару из таблицы и возвращает удаленное значение.
    *   `hash(K key)`: Вспомогательный метод для вычисления индекса на основе `hashCode()` и размера таблицы.
    *   `size()` и `isEmpty()`: Методы для контроля состояния коллекции.

### 2. Система учета автопарка (Вариант 9)

Демонстрация использования встроенного класса `java.util.HashMap` для решения прикладной задачи учета автомобилей.

*   **Класс `Car`:**
    *   Описывает сущность «Автомобиль».
    *   Поля: `brand` (марка), `model` (модель), `year` (год выпуска).
    *   Содержит конструктор, геттеры/сеттеры и переопределенный метод `toString()` для вывода информации.
*   **Класс `CarFleet`:**
    *   **Ключ:** `String` (государственный номерной знак).
    *   **Значение:** Объект класса `Car`.
    *   **Метод `addCar`:** Добавляет автомобиль в автопарк. Содержит проверку на пустоту номерного знака.
    *   **Метод `findCar`:** Осуществляет поиск автомобиля по номеру.
    *   **Метод `removeCar`:** Удаляет автомобиль из парка по номеру.
    *   **Метод `printAllCars`:** Выводит список всех автомобилей в парке с использованием итерации по `EntrySet`.
