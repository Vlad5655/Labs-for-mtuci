# Лабораторная работа №8: Аннотации, Stream API и Concurrent

## Описание

Данная работа посвящена изучению и практическому применению продвинутых возможностей Java: аннотаций для создания метаданных, Reflection API для динамического анализа кода, Stream API для функциональной обработки данных и средств многопоточности из пакета `java.util.concurrent`. Разработано приложение, которое загружает данные, параллельно обрабатывает их различными методами, помеченными аннотациями, и сохраняет результат.

## Основные концепции

*   **Аннотации (Annotations):** Создание собственной аннотации `@DataProcessor` с `RetentionPolicy.RUNTIME` для хранения метаданных о методах обработки.
*   **Reflection (Отражение):** Использование класса `Method` и методов `getDeclaredMethods()`, `invoke()` для динамического поиска и выполнения кода.
*   **Stream API:** Использование потоков (`stream()`) для декларативной обработки коллекций (фильтрация, маппинг, сортировка).
*   **Многопоточность (Concurrency):** Использование `ExecutorService` и пула потоков (`CachedThreadPool`) для параллельного выполнения задач.
*   **Потокобезопасные коллекции:** Использование `CopyOnWriteArrayList` для безопасной записи результатов из нескольких потоков.

## Реализация заданий

### 1. Создание аннотации (`DataProcessor`)

Определен интерфейс аннотации для маркировки методов-обработчиков.

*   **Настройки:**
    *   `@Retention(RetentionPolicy.RUNTIME)`: Аннотация доступна во время выполнения через Reflection.
    *   `@Target(ElementType.METHOD)`: Аннотация применима только к методам.
*   **Поля:** Содержит элемент `description` для описания назначения обработчика.

### 2. Реализация обработчиков данных (`DataProcessors`)

Класс, содержащий методы, помеченные аннотацией `@DataProcessor`, реализующие различную логику обработки списков строк с использованием Stream API.

*   **Метод `filter`:**
    *   **Логика:** Фильтрация коротких строк (длина менее 5 символов).
    *   **Операции:** `stream().filter().collect()`.
*   **Метод `transform`:**
    *   **Логика:** Трансформация текста (удаление пробелов по краям и приведение к верхнему регистру).
    *   **Операции:** `stream().map().collect()`.
*   **Метод `aggregate`:**
    *   **Логика:** Удаление дубликатов и сортировка по алфавиту.
    *   **Операции:** `stream().distinct().sorted().collect()`.

### 3. Менеджер данных (`DataManager`)

Центральный класс, управляющий жизненным циклом данных и координирующий многопоточную обработку.

*   **Регистрация:** Метод `registerDataProcessor` сохраняет объект, содержащий методы обработки.
*   **Загрузка (`loadData`):**
    *   Чтение файла `input.txt`.
    *   Использование `BufferedReader.lines()` и `Collectors.toList()` для сбора строк в список.
*   **Обработка (`processData`):**
    *   **Анализ:** Проход по всем методам зарегистрированного класса через Reflection (`getDeclaredMethods`).
    *   **Фильтрация:** Проверка наличия аннотации `@DataProcessor` с помощью `isAnnotationPresent`.
    *   **Параллелизм:** Для каждого найденного метода создается задача в `ExecutorService`.
    *   **Динамический вызов:** Выполнение метода через `method.invoke(processor, data)`.
    *   **Сбор результатов:** Результаты из разных потоков добавляются в потокобезопасный список `CopyOnWriteArrayList`.
*   **Сохранение (`saveData`):** Запись итогового списка строк в файл `output.txt`.

### 4. Запуск приложения (`Main`)

Демонстрационный класс, связывающий все компоненты в единую систему.

*   Создает экземпляр `DataManager`.
*   Регистрирует объект `DataProcessors`.
*   Вызывает методы загрузки, обработки и сохранения данных поочередно.
*   Выводит в консоль информацию о работе потоков и результатах обработки.
