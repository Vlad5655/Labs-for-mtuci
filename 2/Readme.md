# Лабораторная работа №2: Объектно-ориентированное программирование на Java

## Описание

Данная лабораторная работа посвящена изучению и практическому применению основных концепций объектно-ориентированного программирования (ООП) в языке Java. В ходе работы реализована иерархия классов «Монстры», демонстрирующая механизмы наследования, инкапсуляции, полиморфизма и абстракции. Программа моделирует создание различных существ с уникальными характеристиками, общими базовыми свойствами и поведением.

## Основные концепции ООП в проекте

*   **Абстракция:** Использование абстрактного класса `Monster` для определения общей структуры сущностей без необходимости создания их экземпляров напрямую. Абстрактный метод `showInfo()` задает интерфейс для вывода информации.
*   **Инкапсуляция:** Использование модификаторов доступа `private` (в дочерних классах) и `protected` (в базовом классе), а также методов доступа (геттеров и сеттеров) для защиты данных объекта и управляемого взаимодействия с ними.
*   **Наследование:** Создание иерархии классов с помощью ключевого слова `extends`. Дочерние классы (`Goblin`, `Mermaid`, `Dragon`) наследуют поля и методы родительского класса `Monster`, используя ключевое слово `super` для вызова конструкторов.
*   **Полиморфизм:**
    *   *Переопределение методов:* Использование аннотации `@Override` в дочерних классах для реализации специфического поведения метода `showInfo()`.
    *   *Перегрузка методов:* Реализация в базовом классе двух вариантов метода `hit()` — с одним параметром и с двумя параметрами.
*   **Статические члены:** Использование статической переменной `count` для подсчета общего количества созданных объектов-наследников.

## Структура проекта

Проект включает в себя иерархию классов в соответствии с вариантом задания (Монстры: Гоблин, Русалка, Дракон):

### 1. Абстрактный класс `Monster`
Является базовым уровнем иерархии.
*   **Поля:** `name` (имя), `health` (здоровье), `danger` (опасность) с модификатором `protected`.
*   **Статическое поле:** `count` — счетчик созданных объектов.
*   **Конструкторы:** Реализован конструктор с параметрами и конструктор по умолчанию.
*   **Методы:**
    *   Геттеры и сеттеры для всех полей.
    *   `showInfo()`: Абстрактный метод, требующий реализации в потомках.
    *   `hit(int damage)`: Метод нанесения урона (уменьшает здоровье).
    *   `hit(int damage, String type)`: Перегруженный метод, принимающий тип атаки.

### 2. Наследуемые классы
Реализуют специфику конкретных существ, добавляя по 3 уникальных поля и переопределяя вывод информации.

*   **`Goblin.java`** (Гоблин)
    *   **Поля:** `tribe` (племя), `cunning` (хитрость), `weapon` (оружие).
    *   **Реализация:** Конструкторы используют `super()` для инициализации базовых полей. Метод `showInfo()` выводит характерные для гоблина атрибуты.

*   **`Mermaid.java`** (Русалка)
    *   **Поля:** `ocean` (океан), `singPower` (сила пения), `speed` (скорость).
    *   **Реализация:** Аналогичная структура классу `Goblin` с уникальным выводом в `showInfo()`.

*   **`Dragon.java`** (Дракон)
    *   **Поля:** `element` (стихия), `wingspan` (размах крыльев), `firepower` (огненная мощь).
    *   **Реализация:** Содержит специфические параметры и логику отображения.

### 3. Класс `Main`
Демонстрационный класс для запуска программы.
*   **Создание объектов:** Инициализация экземпляров `Goblin`, `Mermaid`, `Dragon` с помощью параметризованных конструкторов.
*   **Демонстрация возможностей:**
    *   Вызов методов `showInfo()` для каждого объекта.
    *   Использование геттеров (`getName()`, `getHealth()`) и сеттеров (`setName()`) для доступа к данным.
    *   Вызов перегруженных методов `hit()` с разным количеством аргументов.
*   **Полиморфизм:** Создание массива типа `Monster`, содержащего ссылки на объекты разных дочерних классов. Итерация по массиву с вызовом метода `showInfo()`.
*   **Статика:** Вывод общего количества созданных монстров через `Monster.getCount()`.
