# Лабораторная работа №1: Знакомство с Java и базовые алгоритмы

## Описание

Данная работа является вводной и направлена на освоение базового синтаксиса языка Java, работу с командной строкой, компилятором (javac) и виртуальной машиной Java (JVM). В ходе выполнения работы реализованы алгоритмы поиска простых чисел в заданном диапазоне и анализ строк на предмет палиндрома. Работа закрепляет навыки использования циклов, методов работы со строками и обработки аргументов командной строки.

## Основные концепции

*   **Структура Java-приложения:** Организация кода в классы с публичным методом `main`, являющимся точкой входа в программу.
*   **Циклы:** Использование цикла `for` для итерации по числовым последовательностям и индексам символов в строке.
*   **Строки (String):** Работа с объектами класса `String`, получение длины строки через `length()` и доступ к символам по индексу через `charAt()`.
*   **Сравнение значений:** Использование метода `.equals()` для корректного сравнения содержимого строк.
*   **Аргументы командной строки:** Обработка массива `args` для взаимодействия с программой при запуске.

## Структура проекта

В репозитории представлены две основные программы, реализующие алгоритмические задачи:

### Primes.java

Программа для поиска и вывода всех простых чисел в диапазоне от 2 до 100.

*   **Метод `isPrime(int num)`**:
    *   Определяет, является ли аргумент простым числом.
    *   Реализует алгоритм проверки деления с оптимизацией: цикл перебирает делители от 2 до квадратного корня из числа (`i*i <= num`).
    *   Использует оператор остатка от деления `%` для проверки делимости.
*   **Логика main:**
    *   Организован цикл `for` для перебора чисел от 2 до 100 включительно.
    *   Числа, для которых метод `isPrime` вернул `true`, выводятся в консоль.

### Palindrome.java

Анализатор строк, определяющий, является ли переданное слово палиндромом.

*   **Обработка ввода:**
    *   Программа перебирает аргументы командной строки (`args`), позволяя проверять несколько слов за один запуск.
*   **Метод `reverseString(String vord)`**:
    *   Принимает исходную строку и возвращает её в обратном порядке.
    *   Реализован с помощью цикла `for`, который проходит от последнего индекса строки (`vord.length() - 1`) до начального (`0`).
    *   Символы добавляются к результирующей строке с помощью метода `charAt()`.
*   **Метод `isPalindrome(String vord)`**:
    *   Сравнивает исходную строку с её перевернутой версией.
    *   Для сравнения используется метод `.equals()`, возвращая логическое значение (`true` или `false`).
*   **Вывод:**
    *   Для каждого проверенного слова выводится сообщение о том, является ли оно палиндромом (например, `madam -> palindrome`).
