# Лабораторная работа №7: Многопоточность в Java

## Описание

Данная работа посвящена изучению механизмов многопоточного программирования в Java. В ходе выполнения заданий освоены способы создания потоков через реализацию интерфейса `Runnable` и использование лямбда-выражений, механизмы синхронизации с помощью метода `join()` и использование высокоуровневых средств синхронизации из пакета `java.util.concurrent`, таких как `CyclicBarrier`.

## Ключевые концепции

*   **Thread:** Базовый класс для создания и управления потоками выполнения.
*   **Runnable:** Функциональный интерфейс для определения задачи, выполняемой в отдельном потоке.
*   **Synchronization (Join):** Метод `join()` позволяет главному потоку ожидать завершения работы других потоков перед продолжением выполнения.
*   **CyclicBarrier:** Синхронизатор, позволяющий набору потоков дождаться друг друга в определенной точке выполнения (барьере). Барьер срабатывает, когда заданное количество потоков вызвали метод `await()`.
*   **Shared Resources:** Доступ к общим переменным и массивам из нескольких потоков.

## Задания

### 1. Многопоточное вычисление суммы элементов массива

Реализована программа для быстрого суммирования элементов массива путем разделения работы между двумя потоками.

*   **Разделение данных:** Исходный массив разделяется на две равные части.
*   **Реализация:**
    *   Создаются два потока, каждый из которых вычисляет сумму своей половины массива.
    *   Используются лямбда-выражения для реализации `Runnable`.
    *   Результаты суммируются в общие статические переменные `sum1` и `sum2`.
*   **Сборка результатов:** Главный поток вызывает метод `join()` для обоих потоков, чтобы гарантировать завершение вычислений перед выводом общей суммы.

### 2. Поиск максимального элемента в матрице

Разработан алгоритм параллельного поиска экстремума в двумерном массиве (матрице).

*   **Параллелизация данных:** Матрица разделяется на строки. Каждая строка обрабатывается отдельным потоком.
*   **Реализация:**
    *   Создается массив потоков `Thread[]`, количество которых равно количеству строк матрицы.
    *   Каждый поток находит максимальное значение в своей строке и записывает его в ячейку общего массива `rowMax`.
*   **Финальная агрегация:** После завершения работы всех потоков (цикл с `join()`) главный поток проходит по массиву `rowMax` и определяет глобальный максимум.

### 3. Моделирование работы склада (Вариант 9)

Реализована многопоточная модель логистического склада с участием 3 грузчиков, использующая механизм барьеров для синхронизации этапов работы.

*   **Сценарий:** Грузчики (потоки) должны одновременно собрать товар для поездки. Только когда все трое готовы, груз отправляется на другой склад, а затем грузчики возвращаются за следующей партией.
*   **Синхронизация:** Используется `CyclicBarrier` с количеством сторон, равным 3.
*   **Реализация:**
    *   Созданы 3 потока на основе класса `Loader`, реализующего `Runnable`.
    *   Внутри цикла каждый грузчик «берет» товар (выводит вес) и вызывает метод `barrier.await()`.
    *   **Действие барьера:** Когда все 3 потока достигли барьера, выполняется действие по выводу общего веса партии и сообщению об отправке на склад.
    *   Процесс повторяется для всех поездок, указанных в массиве `trips`.
