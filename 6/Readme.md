# Лабораторная работа №6: Коллекции и дженерики в Java

## Описание

Данная работа посвящена изучению каркаса коллекций Java Collections Framework. В ходе выполнения заданий реализованы алгоритмы обработки текстовых данных, создание собственной структуры данных на основе дженериков (Generics) и система учета товаров с использованием специализированных потокобезопасных коллекций.

## Ключевые концепции

*   **Collection Framework:** Использование интерфейсов и реализаций, таких как `HashMap`, `ConcurrentHashMap`, `List` (через `ArrayList`).
*   **Generics:** Использование параметров типов (``) для обеспечения типобезопасности при создании универсальных классов.
*   **Comparator и сортировка:** Использование `Collections.sort` и кастомных компараторов для упорядочивания данных.
*   **Потокобезопасность:** Применение классов из пакета `java.util.concurrent` (например, `ConcurrentHashMap`, `AtomicInteger`) для безопасной работы с данными в многопоточной среде.

## Содержание заданий

### 1. Анализ частоты слов (`TopWords`)

Программа считывает текстовый файл и формирует рейтинг топ-10 самых популярных слов.

*   **Обработка данных:** Чтение файла `ttt.txt` с использованием `Scanner`. Слова очищаются от знаков препинания с помощью регулярных выражений и приводятся к нижнему регистру.
*   **Структура хранения:** Используется коллекция `Map<String, Integer>` для подсчета количества повторений каждого слова.
*   **Сортировка:** Map преобразуется в `List`, который сортируется по убыванию значений (частоты) с помощью анонимного класса `Comparator`.
*   **Результат:** Вывод 10 наиболее часто встречающихся слов и их количества.

### 2. Обобщенный стек (`Stack`)

Реализован универсальный класс стека на основе массива.

*   **Дженерики:** Класс параметризован типом ``, что позволяет хранить объекты любого типа.
*   **Структура:** Внутреннее хранилище представлено массивом `data[]`.
*   **Методы:**
    *   `push(T element)`: Добавляет элемент в стек. Выбрасывает исключение, если стек переполнен.
    *   `pop()`: Удаляет и возвращает верхний элемент (LIFO). Выбрасывает исключение, если стек пуст.
    *   `peek()`: Возвращает верхний элемент без его удаления.
    *   `size()`: Возвращает текущее количество элементов.

### 3. Система учета продаж (Вариант 9)

Разработана программа для управления данными о продажах в магазине с использованием потокобезопасных коллекций.

*   **Класс `ProductSales`:** Сущность товара. Содержит поля названия, цены и количества продаж.
    *   **Потокобезопасность:** Для поля `count` (количество) используется `AtomicInteger`, чтобы обеспечить корректность инкремента при многопоточном доступе.
*   **Класс `SalesTracker`:** Менеджер продаж.
    *   **Хранилище:** Используется `ConcurrentHashMap<String, ProductSales>` для хранения пар "Название товара — Объект продаж". Это обеспечивает безопасность при одновременном доступе к карте из разных потоков.
    *   **Метод `addSale`:** Добавляет запись о продаже. Если товара еще нет в карте, он создается методом `putIfAbsent`, затем количество увеличивается.
*   **Аналитика:** Реализованы методы расчета общей суммы выручки (`getTotalSum`) и поиска наиболее популярного товара (`getMostPopularProduct`) путем перебора значений карты.
